# Sample Data & Outputs

## `sample_exam_hall.mp4`

A synthetic 20-second exam-hall clip generated by
[`scripts/generate_sample_video.py`](../scripts/generate_sample_video.py). It
contains three distinct motion windows (2–5 s, 8–11 s, 14–18 s) separated by
still periods, so the pipeline produces exactly three activity segments.

Regenerate or customise it:

```bash
python scripts/generate_sample_video.py sample_data/sample_exam_hall.mp4 \
    --seconds 20 --fps 15
```

## `outputs/`

Pre-generated artefacts from analysing the sample video, so you can see the
expected results without running anything:

| File | Description |
|------|-------------|
| `sample_heatmap.png` | Motion heatmap (JET colormap over the scene). |
| `sample_events.csv` | Exported event log (3 events). |
| `sample_report.pdf` | Full PDF investigation report. |

These were produced with the MOG2 algorithm and object detection disabled
(no model weights required).
